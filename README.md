## 🚀 Sobre o Projeto
Este projeto é uma API RESTful para o gerenciamento completo de tarefas (Tasks). A aplicação permite que os usuários criem, visualizem, atualizem e deletem suas tarefas, além de funcionalidades como definição de prioridades, status e datas.

O objetivo é fornecer um backend robusto, organizado e escalável para aplicações, gerenciadores de projetos pessoais ou qualquer sistema que necessite de um controle de atividades. A API foi construída seguindo as melhores práticas do padrão REST.

---

## 🎯 Funcionalidades
- ✅ **Criar Tarefa:** Endpoint para cadastrar uma nova tarefa com título, descrição, prioridade e data de vencimento.
- ✅ **Listar Todas as Tarefas:** Retorna uma lista com todas as tarefas cadastradas no sistema.
- ✅ **Buscar Tarefa por ID:** Permite consultar os detalhes de uma tarefa específica através de seu identificador único.
- ✅ **Buscar Tarefa por Período:** Permite consultar as tarefas específicas através do seu período (Ex: Tarefas que devo fazer em 1 hora).
- ✅ **Atualizar Tarefa:** Modifica os dados de uma tarefa existente, como título, descrição ou status.
- ✅ **Marcar Tarefa como Concluída/Pendente:** Altera o status de uma tarefa.
- ✅ **Deletar Tarefa:** Remove uma tarefa do banco de dados.

## 🔧 Tecnologias Utilizadas
A API foi construída com as seguintes tecnologias e bibliotecas:

* **[Java](https://www.oracle.com/java/technologies/downloads/):** Linguagem de programação principal do projeto.
* **[Spring Boot](https://spring.io/projects/spring-boot):** Framework que agiliza a configuração e o desenvolvimento de aplicações stand-alone.
* **[Spring Data JPA](https://spring.io/projects/spring-data-jpa):** Facilita a implementação da camada de persistência de dados.
* **[Open Feign](https://docs-spring-io.translate.goog/spring-cloud-openfeign/docs/current/reference/html/?_x_tr_sl=en&_x_tr_tl=pt&_x_tr_hl=pt&_x_tr_pto=tc):** Facilita a criação de clientes de serviço web e a integração enter APIs 
* **[MongoDB](https://www.mongodb.com/):** Banco de dados não relacional utilizado para a persistência dos dados da aplicação.
* **[Gradle](https://gradle-org.translate.goog/?_x_tr_sl=en&_x_tr_tl=pt&_x_tr_hl=pt&_x_tr_pto=tc):** Ferramenta para gerenciamento de dependências e build do projeto.
* **[Lombok](https://projectlombok.org/):** Biblioteca para reduzir a verbosidade do código (boilerplate) com anotações.

## 📖 Documentação (Swagger)
A documentação de todos os endpoints da API foi gerada utilizando **Swagger (OpenAPI)**, o que facilita a visualização e a interação com os recursos disponíveis.

Para acessar a documentação interativa, inicie a aplicação e acesse o seguinte endereço no seu navegador:

**`http://localhost:8081/swagger-ui.html`**

Lá, você poderá ver todos os endpoints, seus parâmetros, corpos de requisição esperados e respostas, além de poder testá-los diretamente pela interface.
